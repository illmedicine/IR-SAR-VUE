Drop the World SAR shield logo here as `logo.png` (recommended: 512x512 PNG with transparent background).

The web app references it as:
  - <link rel="icon"          href="assets/logo.png">  (browser favicon)
  - <link rel="apple-touch-icon" href="assets/logo.png"> (iOS home-screen)
  - <img src="assets/logo.png">                          (top-right corner brand mark on the 3D globe page)

Until the file exists the favicon and corner mark will simply 404; everything else
on the page continues to work.
